# Bulk Quote Email Templates

Use these as the default email sequences for bulk and event orders. Keep the tone direct and scoped. Do not promise production timing until quantity, version count, size, and delivery destination are confirmed.

## 1. First reply to an inbound bulk lead

Subject:

`Re: Custom star map order`

Body:

```text
Hi <First name>,

Yes, we can help with that.

We can create a custom star map for <location / event> and handle this as a manual bulk order. We can also support multiple versions if needed and can keep branding subtle in the layout.

For a request like this, I’d want to confirm the final specs first and then send you a formal quote plus a proof plan before production.

To scope it accurately, could you send:
- the exact event date or date range
- the location details you want used for the map
- total quantity
- how many distinct versions are needed
- preferred size
- preferred format if known
- delivery deadline
- shipping destination
- logo file if branding is required

Once I have that, I can send back:
- a formal quote
- estimated production and delivery timing
- a proof plan for approval

Best,
<Your name>
StarMapCo
```

```text
Best,
<Your name>
StarMapCo
```

## Guardrails
- Lead with unframed unless the buyer asks for framed.
- Do not promise foldable packaging unless you have intentionally scoped that workflow.
- Do not commit to a final delivery date until the proof is approved.
- Keep multiple-version jobs priced above the simple one-design floor.
