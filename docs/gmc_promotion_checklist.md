# GMC Promotion Setup Checklist

## Steps
1. Verify account access
   - Expected state: User has necessary permissions
   - Rollback: Contact admin to review permissions

2. Create promotional item
   - Expected state: Item is created in the Merchant Center
   - Rollback: Delete the promotional item if incorrect

3. Set promotion details
   - Expected state: All fields filled correctly
   - Rollback: Re-enter details and save

4. Review promotion preview
   - Expected state: Promotion renders as intended
   - Rollback: Adjust settings as needed

5. Launch promotion
